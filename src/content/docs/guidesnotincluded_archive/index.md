实用网站

## 实用网站

THE WIKI

[https://oxygennotincluded.wiki.gg/](https://oxygennotincluded.wiki.gg/wiki/Oxygen_Not_Included_Wiki)

这个 Wiki 上有复制人、资源、小动物、间歇泉、小行星等等，几乎游戏里能找到的一切信息。

PROFESSOR OAKSHELL'S LAB

<https://zari.rtk0.net/ProfessorOakshell/index.html>

里面有一堆好用的计算器，包括食物、耕种、热量和火箭。

(TOOLS NOT INCLUDED)

[(https://toolsnotincluded.net)](https://toolsnotincluded.net/map-tools/map-browser)

Tools Not Included 可以让你浏览地图，帮你找到一张恰好有你想要的间歇泉和星球的地图。可惜这个网站已经挂了一段时间了，不过还有希望回来。

ONI ASSISTANT

[https://oni-assistant.com](https://oni-assistant.com/)

Oni Assistant 网站有很多好用的工具，包括一个食物计算器，以及一个能算出你的火箭需要多少燃料的计算器（本体游戏里）。

THE DEVELOPER'S FORUMS

[https://forums.kleientertainment.com](https://forums.kleientertainment.com/)

在 Klei 的论坛上，你可以读到游戏的更新消息、了解模组、提交建议或错误报告等等。

REDDIT

[https://www.reddit.com/r/Oxygennotincluded](https://www.reddit.com/r/Oxygennotincluded/)

Reddit 的《缺氧》版块是个聊游戏、看建造方案、或者问自己遇到的问题的好地方。

DISCORD

<https://discord.gg/EBncbX2>

《缺氧》的 Discord 里有公告、游戏更新信息、讨论等等。

YOUTUBE

各种频道，有些还带教程。

一些例子：[Anarod](https://www.youtube.com/@Anarod)、[Blitz After Dark](https://www.youtube.com/c/BlitzAfterDark)、[Brothgar](https://www.youtube.com/user/Brothgar)、[Cryptic Fox](https://www.youtube.com/user/CrypticFoxGaming)、[Echo Ridge Gaming](https://www.youtube.com/c/EchoRidgeGaming)、[Francis John](https://www.youtube.com/user/MrFranciscraven)、[GCFungus](https://www.youtube.com/@GCFungus)、[Grind This Game](https://www.youtube.com/channel/UC6STTjHxnSXp-r8NPQIutAQ)、[Luma plays](https://www.youtube.com/c/Lumaplays1)、[Magnet](https://www.youtube.com/user/xunlucky17x)、[Mullematsch](https://www.youtube.com/c/Mullematsch/)、[Nathan's Sandbox](https://www.youtube.com/c/RedstoneNightmare)[,](https://www.youtube.com/c/RedstoneNightmare) [Nilaus](https://www.youtube.com/c/Nilaus)、[QuantumZari](https://www.youtube.com/@QuantumZari)、[Skye Storme](https://www.youtube.com/playlist?list=PLbCLzFKeiWkM69zrZKMIO0VB_vc6sPMbU) 和 [Toni Advanced](https://www.youtube.com/channel/UC3LfCJ2vQi-vSP6JXLG6l5w)（还有 Josh 在 [Let's Game it Out](https://www.youtube.com/watch?v=qIuRghe1EZU) 里折腾《缺氧》的那些乐子）

STEAM GUIDES

[steamcommunity.com/app/457140/guides/](https://steamcommunity.com/app/457140/guides/)

Steam 上有很多很棒的指南，都是玩家写的，几乎覆盖了你想学的任何东西。特别要提一下 Kharnath 的 [Compendium of Amazing Designs](https://steamcommunity.com/sharedfiles/filedetails/?id=2154398396)。

关于

## 关于

嗨，我是某个随机的芬兰人。如果我告诉你这些年我玩了多少千小时的《缺氧》，你多半会忍不住想两件事：一是觉得我很懂行（并没有），二是觉得我常用的那些设计都背下来了（也没有）。

社区整理出来的那些资源、指南和建造方案，对我学会怎么给我的复制人拼凑出一个勉强能过的生活帮助巨大。我建这个网站，是为了回报这个超棒的社区。至少官方说法是这样。

说实话，我建这个网站，是为了不用一次又一次花上几个小时在 YouTube 视频里点来点去，找建造方案里的设置和概览图。（但如果有人问起，你就说是为了社区。）

## 隐私政策

这个网站是用一个叫 Wix 的商业服务搭建并托管的。因为好用，而且我懒。他们保留在本站放置 Cookie 的权利。（抱歉。本站的目标是零 Cookie，但那我得先学会 WordPress 之类的东西。问题就出在“懒”这点上。）

我没有在本站放置任何 Cookie，也没有授权任何第三方在本站放置

Cookie。我不收集本站访问者的数据。我不共享也不出售本站访问者的数据。

作为一条通用的隐私小贴士：你可以借助电子前哨基金会（Electronic Frontier Foundation）的浏览器插件 [Privacy Badger](https://privacybadger.org/) 来拦截部分跟踪，并看到哪些网站在试图跟踪你。我自己就在用，也强烈推荐。
